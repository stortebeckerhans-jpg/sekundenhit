      Verbindungstest

      Prüft, ob echte Song-Ausschnitte geladen werden können.

        Neue Songs hinzufügen

        Öffne die HTML-Datei in einem Editor und suche nach HIER NEUE SONGS HINZUFÜGEN (Array RAW_SONGS). Pro Song eine Zeile:

        { title:"Songtitel", artist:"Interpret",
  genre:["Pop","Aktuell"],
  popularity:8,        // 1–10: wie bekannt?
  introDifficulty:4,   // 1–10: wie schwer ist der Anfang?
  aliases:["Alt. Schreibweise"],   // optional
  audioUrl:"", coverUrl:"", audioStart:0 }  // optional

        Schwierigkeit

        Wird automatisch berechnet: Score = 0,5 × (10 − popularity) + 0,5 × introDifficulty. Unter 3,5 = leicht, ab 5,0 = schwer, dazwischen mittel. Ein sehr bekannter Song mit unscheinbarem Anfang landet so trotzdem auf „Schwer“. Mit difficulty:"easy|medium|hard" kannst du es pro Song überschreiben.

        Audioquellen (austauschbar)

        • audioUrl am Song: eigene, rechtmäßig nutzbare Datei oder Stream (z. B. lizenziert oder Eigenproduktion).
        • iTunes-Vorschau (Standard): kostenlose Apple-Search-API, kein Key, keine Dateien bei dir. Die Vorschau startet meist mitten im Song, nicht am echten Intro. Bitte die Nutzungsbedingungen von Apple beachten.
        • Demo-Ton: automatischer Fallback, wenn keine Quelle erreichbar ist.

        Weitere Quellen baust du im Block AUDIO_PROVIDERS im Script ein.
